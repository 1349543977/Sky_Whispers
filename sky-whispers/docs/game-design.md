# Sky Whispers 游戏设计文档

## 1. 游戏概述

**云端气象局 (Sky Whispers)** 是一款结合放置治愈与社交互助的微信小游戏，以真实天气数据驱动游戏内生态，玩家在浮岛上种植天气植物、捕获天气精灵、与好友互动。

## 2. 核心玩法规则

### 2.1 天气系统

- 游戏天气基于玩家真实地理位置的天气数据
- 每小时自动同步一次天气
- 玩家也可手动触发同步
- 天气类型：晴天、多云、雨天、暴风雨、雪天、雾天、大风

### 2.2 种植系统

- 玩家在浮岛上种植天气植物
- 植物有 4 个生长阶段：种子(0) → 发芽(1) → 生长中(2) → 成熟(3)
- 浇水可加速生长（+10~14 进度）
- 天气、光照、湿度影响生长速度
- 成熟后收获获得金币和经验

### 2.3 精灵系统

- 不同天气条件下出现不同精灵
- 捕获率受稀有度和天气影响
- 精灵可喂食增加幸福度
- 幸福度影响精灵能力

### 2.4 步数系统

- 玩家每日步数转换为风之力
- 风之力驱动风车产出金币
- 每日步数上限 50000

### 2.5 社交系统

- 添加好友互送礼物
- 访问好友岛屿互动（浇水、送微风）
- 礼物 7 天后过期

## 3. 数值平衡表

### 3.1 生长速率

| 天气 | 生长倍率 | 说明 |
|------|---------|------|
| 晴天 sunny | 1.2 | 阳光充沛 |
| 多云 cloudy | 1.0 | 标准 |
| 雨天 rainy | 1.5 | 水分充足 |
| 暴风雨 stormy | 0.8 | 恶劣环境 |
| 雪天 snowy | 0.6 | 严寒 |
| 雾天 foggy | 0.9 | 光照不足 |
| 大风 windy | 1.1 | 通风良好 |

**生长公式：**
```
growthIncrement = elapsedHours × weatherMultiplier × (0.5 + 0.25 × lightFactor + 0.25 × moistureFactor)
lightFactor = lightLevel / 100
moistureFactor = moistureLevel / 100
```

### 3.2 步数转风之力

| 步数 | 风之力 | 说明 |
|------|--------|------|
| 100 | 1 | 基础比率 |
| 1000 | 10 | - |
| 5000 | 50 | - |
| 10000 | 100 | - |
| 50000 | 500 | 每日上限 |

**公式：** `windPower = floor(steps / 100)`

### 3.3 风车金币产出

| 风车等级 | 每分钟产出（风之力=100） | 每小时产出 |
|---------|----------------------|-----------|
| 1 | 10 | 600 |
| 2 | 20 | 1200 |
| 3 | 30 | 1800 |
| 5 | 50 | 3000 |
| 10 | 100 | 6000 |

**公式：** `coinsPerMinute = windmillLevel × windPower × 0.1`

### 3.4 精灵捕获率

| 稀有度 | 基础修正 | 天气匹配加成 | 道具加成范围 |
|--------|---------|------------|------------|
| common | ×1.0 | ×1.5 | 1.0-2.0 |
| uncommon | ×0.8 | ×1.5 | 1.0-2.0 |
| rare | ×0.6 | ×1.5 | 1.0-2.0 |
| epic | ×0.4 | ×1.5 | 1.0-2.0 |
| legendary | ×0.2 | ×1.5 | 1.0-2.0 |

**公式：** `catchChance = baseCatchRate × rarityModifier × weatherBonus × itemBonus`
