# 微信小游戏真机调试问题排查指南

## 问题现象

你可能遇到的问题：

1. **真机调试时无法连接后端 API**
2. **调试服务连接失败**（如截图中的 "ECONNREFUSED" 错误）
3. **手机和电脑不在同一局域网**

---

## 解决步骤

### 第一步：确保手机和电脑在同一局域网

✅ **检查清单：**
- 手机和电脑连接的是**同一个 Wi-Fi**
- 关闭手机的 VPN/代理
- 关闭电脑的防火墙或允许微信开发者工具通过

---

### 第二步：获取电脑的局域网 IP 地址

**Windows:**
```cmd
ipconfig
# 查找 "IPv4 地址"，通常是 192.168.x.x 或 10.x.x.x
```

**macOS/Linux:**
```bash
ifconfig
# 或
ip addr
# 查找 "inet" 地址，通常是 192.168.x.x 或 10.x.x.x
```

**微信开发者工具快捷方式：**
1. 点击右上角「详情」
2. 查看「本地设置」或「基本信息」
3. 通常会显示你的局域网 IP

---

### 第三步：更新后端绑定地址

默认情况下，后端可能只绑定到 `127.0.0.1`，手机无法访问。

修改 `backend/src/app.ts`，让后端监听所有网络接口：

```typescript
// 将：
app.listen(PORT, '127.0.0.1', () => {

// 改为：
app.listen(PORT, '0.0.0.0', () => {
```

或者检查你的 [app.ts](file:///workspace/sky-whispers/backend/src/app.ts) 文件中的监听配置。

---

### 第四步：更新小游戏 API 地址

修改 [BootScene.ts](file:///workspace/sky-whispers/frontend/minigame/src/scenes/BootScene.ts) 第 50 行：

```typescript
// 将 localhost 替换为你的局域网 IP
const apiBaseUrl = 'http://192.168.0.101:3000'; // 示例，请替换为你的 IP
```

**注意：**
- 使用 `http://`，不是 `https://`（开发环境）
- 端口号保持 3000（或你在 .env 中配置的端口）
- IP 地址是你电脑的局域网 IP，不是 127.0.0.1

---

### 第五步：配置微信开发者工具

1. 打开微信开发者工具
2. 点击右上角「详情」
3. 进入「本地设置」
4. ✅ 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」
5. ✅ 确保「调试基础库」版本较新（建议 2.0 以上）

---

### 第六步：重新编译和调试

1. 在微信开发者工具中点击「编译」
2. 点击「预览」生成二维码
3. 用手机微信扫码
4. 确保手机在同一 Wi-Fi 下

---

## 常见问题与解决方案

### 问题 1：调试服务连接失败（ECONNREFUSED）

**症状：**
```
failed to connect to /192.168.0.101 (port 8001)
ECONNREFUSED (Connection refused)
```

**解决方案：**
1. **这是微信调试服务的问题，不是我们的后端 API 问题**
2. 尝试关闭微信开发者工具，重新打开
3. 尝试在微信开发者工具中点击「清缓存」→「全部清除」
4. 确保没有其他程序占用 8001 端口
5. 尝试重启电脑和手机

---

### 问题 2：真机调试时 API 请求失败

**症状：**
- 游戏一直卡在加载界面
- 控制台显示网络请求失败

**解决方案：**
1. 确认后端服务正在运行（`npm run dev`）
2. 确认后端绑定到 `0.0.0.0`（不是 127.0.0.1）
3. 确认小游戏中的 API 地址使用局域网 IP
4. 在手机浏览器中尝试访问 `http://你的IP:3000/api/v1/health`（如果有健康检查接口）
5. 检查电脑防火墙是否阻止了 3000 端口

---

### 问题 3：手机可以 ping 通电脑，但无法访问 API

**症状：**
- `ping 192.168.0.101` 成功
- 但 API 请求超时

**解决方案：**
1. 检查后端是否真的在监听 `0.0.0.0`
2. 检查是否有安全软件（如 360、火绒等）阻止了连接
3. 尝试临时关闭电脑防火墙测试
4. 检查后端服务是否真的在 3000 端口运行

---

## 验证测试

### 测试 1：检查后端是否可被局域网访问

在电脑浏览器中访问：
```
http://127.0.0.1:3000  (应该能访问)
http://你的局域网IP:3000  (也应该能访问)
```

如果第二个无法访问，说明后端只绑定到了 localhost。

### 测试 2：检查手机是否能访问后端

在手机浏览器中访问：
```
http://你的电脑局域网IP:3000
```

如果能访问，说明网络没问题。

## 临时解决方案：使用 ngrok 内网穿透

如果局域网调试有问题，可以使用 ngrok 临时方案：

1. 下载并安装 ngrok：https://ngrok.com/
2. 运行：
   ```bash
   ngrok http 3000
   ```
3. 复制 ngrok 提供的 https 地址
4. 更新小游戏中的 API 地址为 ngrok 地址
